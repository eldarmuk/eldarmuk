# Hi, I'm Eldar

I enjoy working on problems where understanding the data can make something easier for someone else. That has led me to build an AI admissions assistant, research health events in wearable data, and start Afterwit.ai for practising professional conversations.

I like both the technical work and the conversations that help me understand what people actually need.

## What I've been working on
